AI 号池管理器 —— 先看这里
========================================

怎么开始
  1. 双击「AI号池管理器.exe」
  2. 浏览器会自动打开管理界面（地址形如 http://127.0.0.1:8320）
  3. 看「概览」左上角：绿点 + 「运行中」就是正常

三个常做的事
  · 加账号：账号与提供商 → + 添加账号，按提示在 auth.openai.com/codex/device
            输入页面给出的设备码，登录完自动入池
  · 给客户端用：概览 → 客户端接入，复制 Base URL 和 Key 填进 Codex 等客户端
  · 退出程序：设置 → 退出程序（直接关浏览器不会关服务）

另外几件事（新版）
  · 看额度：账号与提供商页的「剩余额度」列，显示每个号还剩多少、什么时候刷新
  · 看订阅：每个号下面写「订阅至 xxxx-xx-xx」，那是真订阅到期日
  · 看活跃：同一行的「最近调用」列，这个号最近 3 小时被用了多少次
  · 重置额度：同一行的「用一次」，消耗一次重置机会立刻恢复（不可撤销）
  · 看调用量：概览 →「请求记录」，上面一行是全部，下面一行一个号（30 天方块）
            模型测试发出的请求也算在里面，所以测完能看到调用数上涨
  · 接中转站：同一页下半部分「第三方提供商」→ 添加，填地址 / Key / 模型即可
  · 验模型：模型测试 → 勾账号和模型 → 开始测试，看实际是哪个模型在服务
            提供商里的模型也在这一页（下面那组），直连中转站核对，不用选账号
            （标「库外」的模型不在指纹库里，只能看「最接近谁」）

注意
  · exe 必须和同目录的 _internal 文件夹待在一起，别只把 exe 单独拷到桌面
    （会弹 Failed to load Python DLL，那不是程序坏了，是少了运行库）
  · 程序不用安装，整个文件夹拷到哪都能用；配置和账号都在 data 目录里
  · data\pool\auths 里是账号登录凭据，等于密码，别外发
  · 端口被占用会自动往后换一个，实际地址看界面左下角
  · 程序没有数字签名，杀软或 SmartScreen 提示时选「仍要运行」

详细说明见同目录「使用说明.md」。
